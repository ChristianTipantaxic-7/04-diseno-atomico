## 🚀 Instrucciones
1. Haz un Fork de este repositorio.
2. Abre tu fork en GitHub Codespaces.
3. Crea la rama `entrega/nombre-apellido`.
4. Completa los 4 retos en `src/components/`.
5. Verifica con `pnpm run test:all`.
6. Abre el Pull Request comparando `entrega/nombre-apellido` contra `main` del repo docente.

## 🆘 Si te trabas
- Revisa `PISTAS.md` (3 niveles de andamiaje por reto).
- **Nunca te quedes con 0**: si no terminas, abre PR con avance parcial. Los 5.0 pts del screencast oral se rescatan igual.
